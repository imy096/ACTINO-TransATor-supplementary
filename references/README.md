# Citation management

- `REFERENCES_APA7.md`: validated APA 7 references. Works with >20 authors correctly use the **first 19 authors, ellipsis, final author** convention.
- `references_APA7.bib`: BibTeX citations (long consortium lists use `and others` so BibTeX output is abbreviated). For the full author lists of the two consortium works, import the DOI directly into Zotero/EndNote; the APA 7 display is complete under APA rules.
- `references_APA7.ris`: RIS entries; works with very large author lists are intentionally shortened and annotated, and should be refreshed from their DOI before a reference-manager submission.
- `reference_metadata_verified.tsv`: per-citation DOI and bibliographic data.

Do **not** use the APA reference list for a direct BMC Genomics upload: the BMC version has Vancouver-style numeric citations. Both styles are retained because the destination journal is not final.
