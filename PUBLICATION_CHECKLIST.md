# Author review before public release

- [ ] The selected public data are complete for all numerical claims in the *final* manuscript version.
- [ ] Genome collection / BioSample locations and dates are validated against the original records; no unsupported "Algerian isolates" claims.
- [ ] Original antiSMASH version, commands, flags, reference input accessions and raw output gaps are documented accurately.
- [ ] Source datasets' original identifiers and accessions are correct.
- [ ] Source-code authors and dataset contributors approve public release.
- [ ] No credentials, unpublished personal records or restricted third-party data are exposed.
- [ ] A licence compatible with authors' publication plans is selected.
- [ ] Repository commit/tag and (if chosen) real Zenodo DOI are recorded and cited.
- [ ] Journal manuscript and uploaded supplementary files match the archived GitHub release.
